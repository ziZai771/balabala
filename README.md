# balabala

本地优先的中文小说阅读器（Android），支持 TXT/MD 导入、在线文章提取、翻页/滚动双模式、多音色朗读。

## 功能清单

### 书架与导入
- 本地 TXT / MD 文件导入（系统文件选择器）
- 在线链接导入（readability 提取正文，自动去广告）
- 粘贴文本直接阅读
- 阅读进度自动保存与恢复（书架显示百分比）

### 阅读模式
- **翻页模式**：按屏幕高度精确分页，支持滑动/翻页/淡入/无 四种翻页动画
- **滚动模式**：段落级无限滚动，自动扩展章节窗口（前后预加载），无感跨章
- 章节目录弹窗（当前章高亮、正序/倒序、共 N 章统计、点击跳转）
- 书签（添加/移除/撤销，书签图标状态）
- 字号、行距、阅读主题（含夜间模式）、段首缩进排版

### 朗读（TTS）
- 系统 TTS / 自定义音色（音频文件）/ AI 音色（OpenAI、MiniMax、ElevenLabs 等接口）
- 逐行朗读、当前朗读段落高亮跟随
- **滚动模式朗读从当前可视位置开始**（不从头开始）
- 读完整批自动滚动到下一批（滚动跟随）
- 屏蔽词过滤（正文与朗读同步剔除）
- 语速/音量/音色切换、定时停止

### 数据管理
- 导出配置（JSON，SAF 保存）/ 导入配置恢复
- 清除缓存

## 构建

```bash
flutter build apk --release
# 产物：build/app/outputs/flutter-apk/app-release.apk
```

依赖：Flutter 3.x、JDK 17、Android SDK。国内镜像：
```
PUB_HOSTED_URL=https://pub.flutter-io.cn
FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
```
